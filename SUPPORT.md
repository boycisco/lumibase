# Support

Need help with LumiBase? Use the appropriate channel below.

## Usage Questions

For questions about installation, configuration, integration, or using LumiBase, use GitHub Discussions if enabled for this repository.

If Discussions are unavailable, open an issue with the appropriate question or support label.

## Bug Reports

If you believe you've found a bug, open a GitHub issue using the **Bug Report** template.

Include:

- The affected package or application.
- Your environment and relevant versions.
- Steps to reproduce the problem.
- Expected and actual behavior.
- Relevant error messages or logs, with secrets and personal data removed.

## Feature Requests

For new capabilities or improvements, use the **Feature Request** issue template.

For substantial architectural changes, start a discussion before submitting a pull request.

## Security Issues

**Do not report security vulnerabilities through public issues or discussions.**

Follow the private reporting instructions in [SECURITY.md](./SECURITY.md).
